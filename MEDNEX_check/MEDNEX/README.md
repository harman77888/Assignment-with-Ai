# MEDNEX — Digital Healthcare & Patient Care Platform

A professional frontend-only healthcare ecosystem prototype built with HTML5, CSS3 and Vanilla JavaScript.

## Run
Open `index.html` in a browser. For the smoothest local experience, serve the folder with any static HTTP server.

## Portals
- Public website: `index.html`
- Patient: `patient/dashboard.html`
- Doctor: `doctor/dashboard.html`
- Admin: `admin/dashboard.html`

## Demo behavior
- Shared centralized demo data in `js/data.js`
- LocalStorage persistence
- Appointment creation/cancellation/status changes
- Doctor and patient CRUD in admin
- Search/filter/sort
- Notifications
- Responsive sidebars and mobile navigation
- Demo authentication routing

## Important
All healthcare, patient, clinician, laboratory, prescription and billing information is fictional demonstration data. This prototype is not a medical diagnostic system and does not implement real authentication, clinical decision-making, payments or backend security.
